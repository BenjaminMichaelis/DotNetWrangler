# .NET Wrangler

C# Roslyn analyzers and IDE code fixes that encourage explicit null contracts, meaningful test failures, and reviewable warning suppressions.

To try a beta release:

```shell
dotnet add package DotNetWrangler.Analyzers --prerelease
```

See the [getting-started guide](https://benjaminmichaelis.github.io/DotNetWrangler/docs/getting-started.html) for compiler requirements and the [analyzer catalog](https://benjaminmichaelis.github.io/DotNetWrangler/README.html#analyzer-catalog) for rule and code-fix details.
